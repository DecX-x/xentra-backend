# Xentra Backend

Plan 1 backend scaffold in a separate codebase.

## Stack

- Fastify
- TypeScript
- Prisma
- PostgreSQL

## Commands

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run prisma:validate`
- `npm run prisma:generate`

## Routes

- `GET /`
- `GET /health`
- `GET /health/ready`
